# Changelog

All notable changes to Videleum will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-11-05

### Added
- Native desktop application for macOS and Windows built with Rust GPUI + GPUI Kit.
- Complete video collection, archival, and streaming playback system.
- Direct streaming download engine for Bilibili with DASH audio/video parsing, WBI signing, and real-time speed/progress monitoring.
- Independent cookie management for YouTube and Bilibili.
- Automated media metadata extraction and Jellyfin/Emby/Plex NFO support.
- User-visible default storage directories (`~/Movies/Videleum` on macOS, `Videos\Videleum` on Windows).
