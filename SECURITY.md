# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of our software seriously. If you believe you have found a security vulnerability in Videleum, please report it via GitHub draft Security Advisory.

**Please do not report security vulnerabilities through public GitHub issues.**

All vulnerability disclosures will be investigated and addressed promptly.
